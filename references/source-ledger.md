# Source Ledger

This skill is an original synthesis. External sources are used to compare approaches, identify reusable principles, and direct further research. No third-party source code, prose, clips, sound, images, fonts, brand assets, or distinctive sequences are redistributed.

## Open-source motion and workflow references

- [emilkowalski/skills](https://github.com/emilkowalski/skills) — deciding whether motion should exist, frequency-aware restraint, animation critique, vocabulary, and prototype loops; MIT at review time.
- [wondelai/skills](https://github.com/wondelai/skills) — microinteraction anatomy and product-defining signature moments; MIT at review time.
- [Vincentwei1021/video-shotcraft](https://github.com/Vincentwei1021/video-shotcraft) — shot, camera, and sequence language; Apache-2.0 at review time.
- [NousResearch/hermes-agent](https://github.com/NousResearch/hermes-agent) — creative coding and p5.js skill patterns; MIT at review time.
- [Google Material Design motion](https://github.com/material-components) — system motion and platform implementation references; verify the exact package license and current guidance.
- [dexhunter/seedance2-skill](https://github.com/dexhunter/seedance2-skill) — camera, reference-role, rhythm, scene, and sound vocabulary for AI-video direction; MIT at review time. Treat model capabilities and output rights as separately governed and time-sensitive.
- [GreenSock](https://github.com/greensock) — web timeline and interaction-motion implementation examples; verify current package licensing and commercial terms.

Useful mechanisms are re-designed inside this skill’s aesthetic, accessibility, governance, and production framework. Upstream content is never copied simply because it is public.

## Research-only references

- [GitHub Brand Toolkit](https://brand.github.com/) — brand motion as a behavioral system; reference only unless a particular asset explicitly permits reuse.
- Public AI-video storyboard skills or gists without a clear license — structure reference only; do not copy text or templates.
- Motion galleries, title archives, festival reels, social feeds, and studio portfolios — discovery and visual analysis only.

## Rights and authorship

Before reuse:

1. Verify the exact repository, commit/tag, and license.
2. Separate code permission from rights to images, fonts, footage, music, voice, logos, and generated output.
3. Extract general mechanisms rather than copying a recognizable treatment.
4. Do not imitate a living motion designer, studio, filmmaker, or brand signature.
5. Record attribution and limitations in the project source ledger.
6. Treat sources with no explicit license as research-only.
